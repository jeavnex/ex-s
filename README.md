# EX-S

Личное приложение для открытия `ex-fs.net` на Android TV и Android-телефоне.

## Что уже есть

- один universal APK для TV и телефона;
- Android 6.0+ (`minSdk 23`), основная проверяемая конфигурация — Android 10;
- управление пультом и касанием;
- штатная авторизация сайта и сохранение его cookies;
- блокировка всплывающих окон, известных рекламных узлов и переходов с EX-FS на чужие сайты;
- полноэкранное веб-видео;
- проверка новых GitHub Releases и загрузка APK из приложения;
- сборка и тесты только в GitHub Actions.

## Важные ограничения

EX-S не обходит подписку, DRM, географические или государственные ограничения. Приложение не содержит фильмы и не хранит пароль EX-FS. Изменения стороннего сайта могут потребовать обновления фильтров.

Android может показать системное подтверждение установки обновления. Полностью скрытая установка стороннего APK без специальных прав устройства невозможна.

## Получить тестовый APK

Откройте вкладку **Actions**, выберите последний успешный запуск **Проверки EX-S** и скачайте артефакт `ex-s-debug`.

## Настроить подписанные релизы

Для обновлений все APK должны подписываться одним постоянным ключом. В GitHub → Settings → Secrets and variables → Actions нужно добавить:

- `EXS_KEYSTORE_BASE64`
- `EXS_STORE_PASSWORD`
- `EXS_KEY_ALIAS`
- `EXS_KEY_PASSWORD`

Ключ и пароли нельзя публиковать в репозитории или сообщениях. После добавления секретов тег `v0.1.0` запустит релиз и прикрепит `ex-s-universal.apk`.

## Конфиденциальность

Авторизация выполняется непосредственно на `https://ex-fs.net`. EX-S не имеет собственного сервера, не получает введённый пароль и не отправляет cookies разработчику.
